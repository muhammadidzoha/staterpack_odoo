# Odoo Docker Starter Kit

This script generates a complete Docker-based Odoo development environment with PostgreSQL.

It supports:

- Create New Project
- Existing Project (already cloned)
- Odoo version selection (14 → latest)
- PostgreSQL version selection (12 → latest)
- Secure Docker secrets
- Makefile for easy management
- Clean development structure

---

## 📦 Requirements

- Docker (v20+)
- Docker Compose (plugin version: `docker compose`)
- Bash (Linux / macOS / WSL)

---

## 🚀 Getting Started

### 1️⃣ Clone This Repository

```bash
git clone https://github.com/muhammadidzoha/staterpack_odoo
cd your-repository-folder
```

### 1️⃣ Make Script Executable
```bash
chmod +x staterpack_odoo
```

### 1️⃣ Run the Generator
```bash
./staterpack_odoo
```
